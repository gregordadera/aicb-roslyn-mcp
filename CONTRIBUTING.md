# Contributing

Thanks for wanting to help. This repository holds the releases, the documentation,
the agent skills, the GitHub Action and the release notes of `aicb`. The product is
developed by its maintainer and ships under its own license, free below the license
thresholds and commercial above them (see
[`EULA.md`](EULA.md) and [`docs/LICENSING.md`](docs/LICENSING.md)).

## Pull requests

**Pull requests from outside are not accepted** - this includes documentation and
skill texts. The reason is licensing: `aicb` is a commercially licensed product, and
taking over someone else's text would need a separate agreement about the rights to
it. A pull request from outside is closed with a pointer to this file.

What helps just as much: describe the change in an issue or a discussion. Good
suggestions are implemented by the maintainer.

## Where to go

- **Bug:** open an [issue](https://github.com/gregordadera/aicb-roslyn-mcp/issues/new/choose)
  with the bug template. Include `aicb --version` and, for MCP problems, the output of
  `server_info`. Never paste your source code - a description, the tool call and the
  answer are enough.
- **Question, idea, feature request or a correction to the docs:**
  [GitHub Discussions](https://github.com/gregordadera/aicb-roslyn-mcp/discussions).
- **Security issue:** report it privately as described in [`SECURITY.md`](SECURITY.md),
  never as a public issue.
- **Commercial license or support agreement:** `aicb@dadera.de`, see
  [`docs/LICENSING.md`](docs/LICENSING.md).
